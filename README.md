# LINC Dashboard

The [LINC Dashboard](https://dashboard.lincbrain.org) summarizes the LINC project's data on [lincbrain.org](https://lincbrain.org) and [dandiarchive.org](https://dandiarchive.org).

See the [LINC Docs](https://docs.lincbrain.org/dashboard) for more details, including the developer documentation.
